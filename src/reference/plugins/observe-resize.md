## Load

To load the plugin from the `g-composer` component we must use the URL:

- ```https://cdn.graphery.online/graphane/1.0.0-beta/plugins/resize.observer.js```

```html
<g-composer>
  <script type="plugin"
          src="https://cdn.graphery.online/graphane/1.0.0-beta/plugins/resize.observer.js">
  </script>
</g-composer>
```
